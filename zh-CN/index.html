核心功能与规划

坚持 Local-first、Offline-first，无云端账号绑定，零隐性订阅费用。

手机或电脑连入同一 Wi-Fi，打开浏览器即可上传素材、调整排期与即时控制。

局域网多设备发现与多屏同步

自动发现局域网内的其它广告机，一键分发与同步媒体资源与播放列表。

横竖屏适配与商用展示模式

支持横屏/竖屏自由切换、全屏沉浸播放、独立音量与静音控制，以及非标比例背景虚化。

工作方式

安装应用、连接网络、上传媒体、立即播放；关闭浏览器后广告机持续独立运行。

  1. 安装 OfflineSignage 到 Android 广告机或智能电视
  2. 手机/电脑通过局域网 IP 或扫码进入 Web 管理控制台
  3. 上传图片、视频或电子餐牌素材并配置播放列表
  4. 开启全屏播放，关闭管理页面后广告机依然独立稳定播放
