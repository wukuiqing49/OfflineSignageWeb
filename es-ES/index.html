Cómo funciona

Instala, conecta, añade contenido y reproduce. La pantalla sigue funcionando aunque cierres el navegador.

  1. Instala OfflineSignage en un reproductor publicitario Android
  2. Abre el panel desde la dirección LAN o un código QR
  3. Añade imágenes, vídeos o páginas web y crea una lista
  4. Cierra el navegador y deja que la pantalla siga reproduciendo localmente
