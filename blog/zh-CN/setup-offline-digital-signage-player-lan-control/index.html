部署指南

局域网即开即用：无云端依赖的 Android 广告机部署与 Web 控制实操

详细解析 OfflineSignage 如何通过设备内置轻量级 Web 服务器，实现无云端依赖、无数据外泄风险、局域网秒级响应的商业广告屏管理。

2026-08-19 · 阅读时间 5 分钟

Contents

  • Overview

OfflineSignage 是一款专为 Android 电视、平板与广告机打造的本地优先（Local-first）数字标牌与电子餐牌系统。它完全脱离外部云端，由 Android 广告机自身运行微型 Web 服务器，任何同局域网下的手机或电脑均可通过浏览器直接上传素材、编排播放并进行设备管理。

一、 快速入门 4 步流程

  1. 安装启动：在 Android 电视或广告机上打开 OfflineSignage，屏幕自动进入全屏商业就绪模式并显示本地连接 IP。
  2. 扫码配对：手机或电脑连入店内同一 Wi-Fi，用浏览器打开屏幕显示的地址（如 http://192.168.1.105:8080）或相机扫码。
  3. 上传与编排：在网页端上传高清海报图（JPG/PNG）或宣传视频（MP4），拖拽设置停留时长并保存播放列表。
  4. 独立持久播放：点击“立即播放”，电视大屏即刻进入 4K 极清轮播。此时可关闭手机或电脑，广告屏 24/7 独立稳定运行。

四、 常见问题与故障排查速查

异常现象可能原因推荐解决方案
打不开控制网页 控制端与电视未连入同一 Wi-Fi 或端口遗漏 确认连接在相同 Wi-Fi 下，并确保网址末尾带有 :8080 端口号。
画面两边有黑边 素材尺寸与屏幕分辨率不一致 在素材设置中将缩放模式切换为 Fit Screen（保持比例居中） 或 Blur Fill（背景模糊填充）。
电视重启后停在桌面 Android 系统的后台开机自启权限未开放 进入电视系统的「应用管理 → OfflineSignage」，开启「开机自启动」权限。
