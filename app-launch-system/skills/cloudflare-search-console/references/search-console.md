# Search Engine Verification and Indexing

## URL-prefix property

For a Cloudflare Pages hostname, add the exact URL-prefix property:

```text
https://site.pages.dev/
```

Do not select Domain property unless the user owns the DNS zone. `pages.dev` is not the user's DNS zone, so DNS TXT verification is wrong for this case.

## HTML tag

Use the HTML tag generated by the same URL-prefix property. Put it in the server response of the root homepage, not only in client-side JavaScript. Confirm with raw response or View Source, then click Verify.

## HTML file

Use Google's exact downloaded values:

```text
Filename: google1234567890abcdef.html
Body: google-site-verification: google1234567890abcdef.html
```

The filename stays at the site root. The body must match exactly, including the colon and filename. Verify this exact URL before using Search Console's Verify button:

```text
https://site.pages.dev/google1234567890abcdef.html
```

It must return `200`, not a redirect, `403`, `404`, or clean-URL fallback.

## DNS TXT

The common TXT value is:

```text
google-site-verification=TOKEN
```

This is a DNS record value, not HTML file content. It applies to Domain property verification and requires DNS access. Waiting for propagation cannot fix a wrong property type or DNS zone.

## Indexing after verification

1. Open **Sitemaps** and submit `sitemap.xml`.
2. Use **URL inspection** for the homepage.
3. Request indexing for the homepage and key product pages.
4. Check canonical, robots access, mobile usability, and sitemap status.
5. Explain that performance and coverage data may take hours or days to appear.

## Bing Webmaster Tools

For Bing Webmaster Tools, add the exact public site URL and choose one of these configured methods:

- `msvalidate.01` meta tag on the source-locale homepage.
- `BingSiteAuth.xml` at the site root with Bing's exact XML body.

Verify the exact deployed URL before completing the Bing workflow:

```text
https://site.pages.dev/BingSiteAuth.xml
```

Submit the deployed `sitemap.xml`, inspect the homepage and key pages, and check crawl errors. Do not treat successful verification as proof that pages are indexed.

## IndexNow

When `indexNow.key` is configured, the generator creates `/<key>.txt` containing the exact key. After deployment, submit the homepage and changed public URLs to an IndexNow endpoint. Keep the key file in the public manifest; do not put private source files in the deployment.
